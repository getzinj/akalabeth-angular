# Applesoft oracle tools

Offline tools that run the real Applesoft II ROM in the [py65](https://github.com/mnaberez/py65) 6502
emulator and record what it does, so the TypeScript port can be checked against it. Nothing here runs in CI
and nothing it builds is committed: the ROM image is Apple's.

## Setup

```sh
apt-get install m4 xa65   # assembler used by the reconstructed source
pip install py65
./build-rom.sh            # clones cmosher01/Apple-II-Source at a pinned commit, assembles
                          # rom/applesoft.bin and checks its MD5 against the one published there
```

`rom/` is gitignored.

Also run `./fetch-listing.sh`, which downloads `AKLABETH.TXT` at the pinned commit into the gitignored
`listing/` and checks its SHA-256.

## The machine

`apple2_machine.py` is an Apple II+ in py65: 48 KB of RAM, Applesoft and the autostart Monitor (both MD5-checked),
the keyboard latch and the display switches. It boots to the `]` prompt, moves the program start to `$4001` (the
program is about 23 KB, so at the default `$0801` it would overlap the hi-res page and the first `HGR` would erase
it), and types the listing in so the ROM tokenises it itself. `listing.py` unwraps the LIST output and applies the
documented corrections. A key is supplied whenever the program polls the keyboard with nothing waiting; Applesoft's
per-statement Ctrl-C check (`ISCNTC`) does not count as waiting.

## Fixtures

```sh
python3 generate_numeric_fixtures.py
```

writes `src/app/runtime/applesoft/fixtures/*.json`: FIN, FOUT, ROUND, the five arithmetic operators as
FRMEVL performs them, INT, SQR, ATN, LOG, EXP, ABS, SGN, unary minus, and RND sequences from a range of seeds
(including the dungeon seeds Akalabeth builds from the lucky number). The generator is seeded, so rerunning it
reproduces the same files.

```sh
python3 generate_game_fixtures.py   # about 15 minutes; caches the typed-in program under rom/
python3 generate_game_fixtures.py input   # one stage only: worlds, dungeons, sessions, dungeon-sessions, scenarios or input
```

writes `src/app/port/fixtures/`: the perspective tables, worlds for 36 lucky numbers, dungeons for three worlds
(three dungeon squares, levels 1-10, generated by the program's own `GOSUB 500` in direct mode), and scripted
sessions recorded key by key. To add a scenario, write a `session_*` function that drives the machine with `press`
and add it to the list in `main`.
